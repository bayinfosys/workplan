# PRINCIPLES.md on the parent branch and publish

workplans/PRINCIPLES.md's branch line names the parent branch as the
one merge squashes into, and publish as the command that pushes.

Effects:

- the line reads: commands write to the checked-out branch only; new,
  which starts a workplan's branch, and merge, which squashes it into
  the parent branch, are the commands that change branches; publish
  is the command that pushes
- no other line of PRINCIPLES.md changes; it stays short

Depends: none
Change: docs
Audience: internal
