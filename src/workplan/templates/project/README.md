# Workplans

Work on this repository is planned and recorded here with the workplan
protocol: https://github.com/bayinfosys/workplan/blob/master/PROTOCOL.md

- `<id>/WORKPLAN.md`: a goal, its context and its tasks
- `<id>/<nnnn>/`: one task, applied as one commit
- `PRINCIPLES.md`: what every task and review holds to
- `BACKLOG.md`: candidate workplans, in order of priority
- `config.toml`: settings for the `workplan` command
- `dispatch.sh`: the steps the `workplan` hooks run after each commit
